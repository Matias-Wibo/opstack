# Criterios operativos confirmados por el equipo Wibo

Estos criterios complementan el centro de ayuda. Se confirmaron directamente en la conversación donde se creó este agente.

## Menú y POS

- Cuando existe integración con un POS, el menú debe mantenerse en el POS y sincronizarse con Wibo. No instruir al comercio a modificar productos integrados directamente en Wibo: las diferencias pueden producir errores de ID o hacer que las órdenes no ingresen al POS.
- Cuando no hay integración con POS, el menú sí debe mantenerse actualizado en Wibo.

## Devoluciones

Primero identifica el origen del pago y el ambiente desde el que se quiere devolver:

| Origen / ambiente | Criterio |
| --- | --- |
| Mercado Pago | Gestionar la devolución en el portal de administración de Mercado Pago. |
| Klap | Gestionar la devolución desde la terminal Klap. |
| Terminal de pago instalada en el tótem | No está permitido realizar devoluciones desde esta terminal. |
| Ambiente de caja de Wibo | Sí está permitido realizar devoluciones desde este ambiente. |

No generalices el procedimiento de un proveedor a otro. Si el cliente no sabe desde dónde se cobró, ayúdale a identificar el origen antes de indicar el flujo.
